# Mobile QA

Use the iPhone tester as a fixed quality check after larger website changes:

https://iphone-test-lakehouse-dalarna.alexander-hjelm.chatgpt.site

Also use the internal preview page:

https://lakehousedalarna.com/mobile-preview.html

This page is not linked from the public site and is marked `noindex,nofollow`.

Check both portrait and landscape:

- Images load on the home page and gallery.
- Menu opens, closes, and links to the right sections.
- Text size is comfortable and does not overlap.
- Page scroll feels natural.
- Buttons are easy to tap.
- Gallery opens photos without timing out.
- Loading time is acceptable on a mobile-sized viewport.
